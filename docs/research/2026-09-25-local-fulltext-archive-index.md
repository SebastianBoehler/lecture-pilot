# Local full-text archive index

Collected 25 September 2026 for later LecturePilot research and implementation
comparison. The 26 PDFs are stored in the gitignored
`full-texts/` directory. The README inside that local directory
records the source URL for each file. This index and bibliography are safe to
track; do not add the PDFs to Git.

“Full text archived” means a complete PDF was downloaded and its title checked.
It does not imply the version of record: files include author manuscripts,
preprints and accepted copies. Two files are dissertations containing the cited
article in a chapter. Publicly downloadable does not mean public domain; keep
copies local for personal research and follow each source's reuse terms.
